🚀 Uygulamayı Çalıştırma

1. Projeyi Klonlayın

git clone https://github.com/ibrahimcemk/react-native-mobil-uygulama-final-projesi.git
cd react-native-mobil-uygulama-final-projesi

2. Backend'i Başlatın

Windows (PowerShell):

cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

Linux/Mac:

cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

3. Frontend'i Başlatın

cd frontend
npm install
npm start

4. Mobil Cihazda Açın

Telefonunuzda Expo Go uygulamasını indirin ve terminal'deki QR kodu taratın.

Android iOS Expo Go

☁️ GitHub Codespaces ile Çalıştırma

Local kurulum yapmadan tarayıcınızda çalıştırın:

1. GitHub'da Açın

Repo sayfasında Code butonuna tıklayın, Codespaces sekmesinden Create codespace on main seçin.

2. Otomatik Kurulum

Container oluşturulurken backend ve frontend bağımlılıkları otomatik yüklenir. MongoDB container da başlatılır.

3. Uygulamayı Başlatın

# Terminal 1
cd backend && source venv/bin/activate && uvicorn app.main:app --reload

# Terminal 2
cd frontend && npm start
